Kabuyomi プライバシーポリシー

最終更新日: 2026-07-11

1. アプリの目的

Kabuyomi は、米国企業の SEC EDGAR 公開 10-K / 10-Q を日本語で読みやすくし、根拠付きの要約、指標表示、AI Q&A、引用文翻訳を提供する SEC filing reader です。投資助言、売買推奨、株価予測、目標株価、証券口座連携、利益保証は提供しません。

2. 収集する情報

Kabuyomi は、アプリの機能提供、利用制限、credit 残高と購入復元、品質改善、障害調査のために、サーバー発行の匿名 installation credential、App Attest の検証結果、検索履歴、保存銘柄、閲覧した企業・提出書類、チャット質問、AI 応答、チャット利用回数、credit 残高、購入検証・復元に必要な最小情報、アプリ内操作、エラーやパフォーマンスに関する診断情報を扱います。旧版からの安全な移行時には、旧 device key の生値ではなく変換済みの照合情報を扱います。氏名、メールアドレス、証券口座情報、保有資産情報、銀行口座情報は通常利用に必要としません。

購入 credit のアカウント復元機能が有効な場合に限り、購入クレジットの復元と新規購入のため Sign in with Apple を任意で利用できます。SEC 資料の閲覧や質問にサインインは不要です。氏名・メールアドレスの scope は要求せず、Apple の生の利用者識別子や本人確認 token は保存しません。サーバー秘密鍵で変換したアカウント識別子、StoreKit の appAccountToken、認証済み端末との関連、購入・移行の監査記録を保持します。

3. SEC 提出資料と AI 利用時に送信される情報

AI チャットや引用文翻訳を利用する場合、入力した質問文、翻訳対象の引用文、対象企業の SEC 提出資料メタデータ、抽出済みの MD&A、抽出済みの XBRL 指標、根拠として使う資料断片を OpenAI API などの外部 AI サービスに送信することがあります。回答はアプリが利用できる SEC 提出資料に基づきます。個人情報、証券口座情報、未公開情報、第三者の機密情報は入力しないでください。

4. 第三者サービス

Kabuyomi は、API 配信、キャッシュ、利用制限管理に Cloudflare、米国企業の 10-K / 10-Q 取得に SEC EDGAR、AI 応答や翻訳に OpenAI API などの外部 AI サービス、広告表示に Google AdMob、アプリ内課金と購入復元に Apple App Store / StoreKit / App Store Server API を利用します。これらのサービスは、それぞれの規約およびプライバシーポリシーに基づいて情報を処理する場合があります。

5. 広告

無料プランなどでは Google AdMob によるバナー広告を表示する場合があります。任意の rewarded credit 操作は、サーバーが機能と配信環境を明示的に許可し、Google AdMob SSV の準備を確認した場合だけ表示します。広告完了だけでは credit を付与せず、SSV を確認した場合に限り反映します。広告配信時は Google AdMob SDK が広告識別子、デバイス情報、利用状況、概算位置情報、広告データ、エラーやパフォーマンスなどの診断情報を扱うことがあります。Kabuyomi は会話本文を妨げるインタースティシャル広告を前提にしていません。

6. 購入・credit・ログ

追加 credit の購入、返金、請求、購入履歴、購入復元は Apple ID と App Store の仕組みに従います。サーバー側では、利用制限、credit 台帳、購入重複防止、運用監査、障害調査に必要な最小限の記録を保持します。SEC 提出資料や抽出済みデータはキャッシュとして再利用されることがあります。

7. 保存と削除

端末内の保存銘柄、取得済み資料、チャット履歴は、設定画面のデータリセットにより削除できます。リセット後も Keychain の匿名 installation credential とサーバーの credit・購入記録は維持され、別の新規残高は作られません。サーバー側の記録の確認・削除依頼はサポート窓口で受け付け、本人確認、購入・会計上必要な保持、適用法、運用上可能な範囲に従って対応します。

8. 国外処理と販売なし

Kabuyomi が利用する Cloudflare、OpenAI、Google、Apple などの第三者サービスでは、日本国外を含む地域でデータが処理・保存される場合があります。Kabuyomi は、利用者の個人データを第三者に販売することを目的としていません。
