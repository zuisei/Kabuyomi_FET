# アプリアイコンの差し替え案(2026-08-24)

## なぜ変えるか

現行アイコンには2つ問題がある。

1. **小さいと読めない。** 60×60(ホーム画面の実寸)にすると、書類・グラフ・吹き出しの
   3つが重なって潰れる。`compare.png` の一番下の段を見ると現行だけ判別できない
2. **アプリの色と合っていない。** F11 でパレットを「墨と抹茶」(暖色の墨 + 生成り + 抹茶)に
   刷新したが、アイコンは茶色 + オレンジのまま。開いた瞬間に色が変わる

## 案

| ファイル | 地 | 字 | 位置づけ |
|---|---|---|---|
| `kabuyomi-icon-sumi-1024.png` | 墨 `#1F1D17` | 生成り + 抹茶の線 | **本命。** アプリの地の色と同じ |
| `kabuyomi-icon-matcha-1024.png` | 抹茶 `#4E6E28` | 生成り + 抹茶の線 | 棚の中で色が立つ。金融アプリは青が多いので目に付く |
| `kabuyomi-icon-mincho-1024.png` | 墨 | 明朝体 | 落ち着くが線が細く、小さいと弱い |

## 考え方

**「読」一文字。** 理由は3つ。

- **名前そのもの**(株読 → Kabuyomi)。アイコンと名前が一致する
- **60px で読める。** 一文字なら潰れない。現行が失敗しているのはここ
- **棚の中で浮く。** 金融カテゴリはローソク足・矢印・グラフばかりで、
  日本語一文字は他に無い。**探して見つけてもらう**のではなく、
  **並んだ中で目に留まる**ための形

下の抹茶色の線は「根拠を引く」。要約ではなく出典を出す、というアプリの建て付けを一本の線にした。

## 注意

- 1024×1024 / RGB / 透過なし(Apple の要件どおり)
- **角丸は焼き込んでいない**。iOS 側がマスクする。`compare.png` はマスク後の見え方
- これは**叩き台**。字面のバランス(「読」の重心がやや上)は詰める余地がある
