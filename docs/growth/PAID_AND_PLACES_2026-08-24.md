# 広告 3,000 円をどう使うか / 他にどこに出すか(2026-08-24)

オーナー「App Store 広告とツイッター広告も予算 3000 までだったら出せる」
「宣伝場所探しといて」への回答。

`CAMPAIGN_PLAN_2026-09.md` は「paid はやらない」としている。**その判断は正しい**が、
前提が「予算ゼロ」だった。3,000 円が出せるなら結論が少し変わる —— ただし
**獲得の手段としてではなく、測定の手段として。**

## 3,000 円で何が買えるか(正直な見積もり)

| | 相場 | 3,000 円で | 実際の DL |
|---|---|---|---|
| **Apple Search Ads** | 1タップ ¥50〜200 | 15〜60 タップ | **2〜8 件** |
| **X 広告** | 1クリック ¥30〜100 | 30〜100 クリック | **0〜3 件** |

**事業は動きません。** 現在の累計 DL が 4 件なので相対的には大きく見えますが、
絶対値としては誤差です。ここは期待しない方がいい。

## それでも出す価値がある理由は1つだけ

**Apple Search Ads は「どの検索語で表示されたか」を返します。**

いま一番足りていないのは、まさにこのデータです。ASO で名前を変えましたが、
**どの語で人が探しているのかは推測でしかありません**。3,000 円は、
その推測を1回だけ実測に変える金額としては妥当です。

なので使い方はこう:

- **Apple Search Ads に全額**。X は使わない
- 理由: **検索広告は「もう探している人」に当たる**。3,000 円しかないなら、
  興味を作る(X)より、既にある興味を拾う方が効率が10倍違う
- キーワードは絞る。**完全一致で 5 語程度**。
  例: `米国株 決算` / `10-K` / `決算書 翻訳` / `決算 英語` / `TSMC 決算`
- **広く配信しない**(自動マッチをオフに)。3,000 円は 1 日で溶ける

## いつ出すか — 今は出さないこと

**v1.2 の名称変更が 2026-08-24 に公開されたばかり**です。
順位反映に 1〜2 週かかります。

**いま広告を出すと、インプレッションが増えた原因が
「名前を変えたから」か「金を払ったから」か分からなくなります。**

→ **9/07 の ASO 再測定が終わってから。** 順序を守れば、
3,000 円で「どの語が効くか」という**次の判断材料**が手に入ります。
順序を破ると、3,000 円で**何も分からなくなります**。

## 私が実行できないこと

キャンペーンの作成・支払い方法の登録・入札設定は **App Store Connect と
広告アカウント側の作業**で、オーナーにしかできません。
キーワード案と、出稿後の数字の読み方は用意できます。

# 宣伝場所

`CAMPAIGN_PLAN_2026-09.md` が App Store / LP・SEO / X を押さえているので、
ここは**そこに無い場所**だけ。

## 前提: どこも「宣伝」は嫌われる

投資系・技術系を問わず、コミュニティは広告を弾きます。通るのは
**それ単体で役に立つもの**だけです。つまり必要なのは宣伝文ではなく
**記事**で、アプリはその末尾に置く。これは campaign plan の方針と同じです。

## 候補

## 私の意見

**Zenn の技術記事が、いちばん確度が高い**と思います。理由は3つ。

1. **書く材料が既にある。** 今日だけで「TSMC は IFRS で出す」「ASML と Shell は
   20-F の本文に Item 見出しが無い」「列の並びが会社ごとに逆」など、
   調べないと分からないことが揃っています
2. **宣伝ではなく記録として書ける。** アプリは「これを作っている過程で分かった」
   という文脈で置ける。嫌われ方をしない
3. **競合がいない。** 日本語で SEC の XBRL を扱った記事はほとんど無い

投資層には直接刺さりませんが、**「作っている人」として認知される**のは、
4 DL の段階では悪くない入り口です。
