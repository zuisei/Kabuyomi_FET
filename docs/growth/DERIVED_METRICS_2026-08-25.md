# 有料データを計算で出せないか(2026-08-25)

オーナー「有料とかになってるデータを計算で求めて出すのはだめなの？」への回答。

**結論: 出せるものと、出せないものと、やってはいけないものが混ざっている。**
そして出せるものは、**今のアプリの一番の強みと相性がいい。**

---

## 1. 提出書類から計算する — 問題ない。むしろやるべき

SEC EDGAR は公開データで、商用利用も認められている(レート制限と User-Agent の
明示は守る必要がある。既に守っている)。**そこから計算した値は自分の計算結果**であって、
誰かのデータの複製ではない。世の中の金融データ会社の多くがまさにこれをやっている。

そして**材料はもう手元にある**。今日 TSMC の XBRL で確認したところ、
いま取っていないだけで**同じ API に USD で入っていた**。

| | タグ | USD |
|---|---|---|
| 自己資本 | `Equity` / `EquityAttributableToOwnersOfParent` | あり |
| 総資産 | `Assets` | あり |
| 設備投資 | `PurchaseOfPropertyPlantAndEquipment…` | あり |
| 棚卸資産 | `Inventories` | あり |
| 研究開発費 | `ResearchAndDevelopmentExpense` | あり |

タグを足すだけで、次が計算できる。

| 指標 | 式 | なぜ効くか |
|---|---|---|
| **ROE** | 純利益 ÷ 自己資本 | 有料端末の看板指標 |
| **ROA** | 純利益 ÷ 総資産 | 同上 |
| **FCF** | 営業CF − 設備投資 | **決算記事がまず書かない**。効く |
| 営業利益率 | 営業利益 ÷ 売上 | 推移で見ると意味が出る |
| 研究開発比率 | R&D ÷ 売上 | 半導体・製薬で効く |
| 棚卸資産回転 | 売上 ÷ 棚卸資産 | 在庫の積み上がりが見える |
| 5年 CAGR | 履歴から | **`metric_history` に 2,811 行ある** |

## 2. 株価が要るものは、計算では出せない

**PER・PBR・時価総額・配当利回り**は、分母か分子に株価が要る。
株価は SEC には無い。取引所のライセンス商品で、無料・遅延のソースはあるが
利用条件がそれぞれ違う。

**ここは「計算で求める」の外側**なので、やるなら別の判断(データ元の契約)になる。
当面は手を出さないのが安全。

## 3. 有料サービスから取ってくるのは、だめ

株探・Bloomberg・FactSet などの画面や API から値を取って出すのは、
利用規約違反であり再配布はライセンス違反になる。**やらない。**

同じ「ROE 24.5%」でも、**提出書類から自分で計算した 24.5%** と
**よそから取った 24.5%** は法的にまったく別物である。前者だけをやる。

---

## ★ ここが肝: 計算した数字には出典が無い

このアプリは「**すべての記述に出典がある**」を建て付けにしている。
ところが **ROE 24.5% は、20-F のどこにも書かれていない。**
そのまま出すと、いちばん大事にしてきたルールを自分で破ることになる。

### 解き方: 答えではなく、式ごと出す

> **ROE 24.5%**
> = 純利益 353.01 億ドル ÷ 自己資本 1,440.32 億ドル
> (いずれも FY2024 の 20-F。それぞれの原文へのリンク)

こうすると、**計算結果に出典が付く**。正確には、計算の**材料**に出典が付き、
式は開いている。読む人は自分で検算できる。

**そしてこれは、有料端末より強い。**Bloomberg は 24.5% という数字をくれるが、
**どの数字をどう割ったかは見せない**。会計基準や定義が違えば値も変わるのに、
利用者は確かめようがない。

**「計算過程が開いている財務指標」は、日本語ではほぼ存在しない。**
これは差別化になる。

### 気をつけること

- **定義を1つに決めて明示する。**ROE の分母を期末自己資本にするか期中平均にするかで
  値が変わる。「どの定義で計算したか」を必ず書く
- **IFRS と US-GAAP を並べるときは注意。**自己資本の中身が同じとは限らない。
  同じ式で出したことを明示し、企業間比較の断定はしない
- **欠けたら出さない。**材料が片方でも無ければ計算しない。
  推定値を混ぜた時点で、このアプリの意味が無くなる

## 実装の規模

- **Worker**: `METRIC_TAGS` に 5 タグ追加 + 派生指標の計算。**小さい**
- **出典の紐付け**: 既存の excerpt / source chunk の仕組みに、
  「この指標は2つの事実から計算した」という関係を足す。**中くらい**
- **iOS**: 式を開いて見せる UI。タップで分子分母とその原文へ。**中くらい**

材料と仕組みが既にあるので、ゼロから作る部分は少ない。
