# gpt-5.6-luna 移行検討(2026-08-24)

オーナー指示「5.6 luna にするのも検討しといて」。test worker の
`OPENAI_CHAT_MODEL` を一時的に `gpt-5.6-luna` へ差し替え、口語ベンチ 36行
(human-phrasing-12 × AAPL/JPM/MA)を実行して nano の同一 36行
(`2026-08-22-human-phrasing-12x15-lkg-aapl-rerun`)と比較した。
実行後は nano に戻して再デプロイ済み(`2026-08-24-luna-ab-36`)。

## 結果

| | gpt-5-nano | gpt-5.6-luna |
|---|---|---|
| critical / 助言 / 英語露出 | 0 / 0 / 0 | 0 / 0 / 0 |
| quality fallback | 4行 | 1行(※Q08 決定論修正が luna 側デプロイにのみ入っており3行分は交絡) |
| モデル呼び出し中央値 | 4.36s | 3.98s |
| 消費トークン中央値 | 4.6k | 4.4k |

**定性**: luna は日本語が引き締まり、nano が漏らした混在英語(「最も直接的な evidenceは」)
が無い。一方 MA-Q05 で「58.7%から58.7%増へ」という壊れた数値表現を1件確認
(nano 側の同設問は正しい 60.2%)。ガード類は両者同じものが効く。

## 判断(推奨)

- **今すぐ本番は切り替えない**。36行では優位は確度不足で、数値表現の乱れも1件ある
- 切り替え判断は **180行 LKG を luna で1本流してから**(手順: wrangler.test.toml の
  `OPENAI_CHAT_MODEL` 差し替え → testbench:run → 戻す。今回のスクリプトを再利用可)
- **価格が未確認**(API からは取れない)。OpenAI ダッシュボードで gpt-5.6-luna の
  単価を確認するのはオーナー作業。5.6 系には sol / terra、nano 系にも gpt-5.4-nano が
  出ており、コスト据え置きの後継として 5.4-nano も同時に測る価値がある
