# Kabuyomi ASO 刷新案(2026-08-21)

現状の診断は `super.md` 第IV部-4 を参照。要点: **需要のある検索語で全て圏外、需要のない「SEC 決算」で1位**。主因は **App Store名が "Kabuyomi" 単体でキーワードを1つも含まない**こと。

Appleの検索ランキング寄与は **アプリ名 > サブタイトル > キーワード欄**。今は一番重い枠を空で出している。

## 制約(Apple仕様)

| 項目 | 上限 | 変更タイミング |
|---|---|---|
| アプリ名 | 30文字 | **新バージョン提出時のみ** |
| サブタイトル | 30文字 | **新バージョン提出時のみ** |
| キーワード欄 | 100文字(カンマ区切り・スペース禁止) | **新バージョン提出時のみ** |

→ **手元の v1.2 提出と同時に行えば追加コストゼロ**(出荷1.0.2から12コミット先行、iOS 201/201通過済み)。

**重要なルール**: 名前・サブタイトル・キーワード欄は**合算でインデックスされる**ので、名前に入れた語をキーワード欄で繰り返すのは枠の無駄。競合アプリ名の使用はリジェクト対象なので入れない。

## 推奨: B案

理由: 実測で「米国株」を含む語のボリュームが最も大きく(SBI・moomoo・Yahoo!ファイナンス等の巨大アプリが並ぶ)、かつ**決算読解の直接競合は評価0〜166件しかいない**。つまり「米国株」の巨大な流れの中で、「決算」「読む」の意図を持つ細い流れだけを拾える位置に名前を置くのが最も効率が良い。

## 差し替え候補のキーワード(A/Bテスト用)

初回で入れなかった語。次バージョンで入れ替えて反応を見る:
`10-K,10-Q,アナリスト,バリュエーション,ファンダメンタル,米国企業,IR,適時開示,有価証券報告書,決算短信`

**注意**: `有価証券報告書` `決算短信` は日本株の書類なので、Kabuyomiの機能(米国SEC)と食い違う。誤解を招く語は入れない(App Storeのメタデータ規約違反リスク+レビュー悪化)。

## スクリーンショットについて(未診断)

App Store の離脱はスクショで決まる割合が大きいが、**現状のスクショは未確認**。App Store Connect の「プロダクトページ表示 → ダウンロード」転換率が業界平均(概ね2〜5%)を大きく下回る場合、原因は名称でなくスクショ側。ユーザーが数字を取得したら再診断する。
