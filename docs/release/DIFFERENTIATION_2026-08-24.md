# 何で差をつけるか(2026-08-24)

オーナー「差別化したいからなんかいい案だしといて」への回答。
マーケ側の**言い方**の話は `CAMPAIGN_PLAN_2026-09.md` にある。
ここは**プロダクトで何を持つか**の話。

## 先に、いちばん大事なこと

**最大の競合は他の決算アプリではなく ChatGPT です。**

「AIが英語の決算を日本語で要約する」は、もう誰でも無料でできます。
10-K の URL を貼れば ChatGPT は読みます。ここで戦っても勝てません。

正直に言うと、Kabuyomi が ChatGPT に勝てるのは次の3つだけです。

| | Kabuyomi | ChatGPT |
|---|---|---|
| **数字の出どころ** | 提出書類の該当箇所に必ず結びつく(コードで強制) | それらしい数字が混ざりうる |
| **蓄積** | 銘柄ごとに過去分・前年同期を持ち、並べて比較できる | 会話ごとに毎回ゼロから |
| **手間** | 銘柄を選べば資料が揃っている | 毎回 URL を探して貼る |

逆に言えば、**この3つを強くしない機能追加は差別化になりません。**
「もっと賢く要約する」方向は、追いつかれる側に立つ道です。

---

## 案1(最有力): 決算が出た瞬間に届く

**なぜ**: いまアプリには「また開く理由」がありません。決算は3か月に1回しか動かず、
その1回を逃すと開く動機がない。**逆に、その1回を捕まえれば必ず開かれます。**
そして **ChatGPT は構造上これができません**(向こうからは来ない)。

**いま何があるか**:
- Worker は既に**毎日 SEC を見に行っている**(`scheduled` + `dailyRefreshEnabled` + `trackedTickers`)
- 提出書類は `filings` テーブルに入る
- 保存銘柄はユーザーごとに持っている

**足りないもの**: **iOS 側に通知が1行も無い**(`UserNotifications` の import すらゼロ)。
APNs の登録・許可・トークン保管・Worker からの送信を作る必要がある。
サーバ半分は既にあるので、**残り半分**という規模。

**出す通知はこれだけでいい**:
> トヨタが年次報告書(20-F)を提出しました。売上は前年比 +6.5%。

数字を1つ入れるのが肝心です。通知だけで用が足りると開かれませんが、
**開かないと出どころが分からない**ので開かれます。

---

## 案2: 「前年から何が変わったか」を主役にする

**なぜ**: 決算を読む人が本当に知りたいのは数字そのものではなく**差分**です。
そして差分は**要約記事が一番苦手**なところ(記事は当期の話しかしない)。

**いま何があるか**: `pickComparisonFiling` で前年同期の提出書類を既に取っている。
盤面のピルにも YoY が出ている。**あるものを主役にしていないだけ**。

**やること**: 会社を開いた最初の画面を「前年からの変化」にする。
売上・利益の増減に加えて、**文章の差分**(リスク要因に増えた項目、
経営陣が新しく言い出したこと)を出せると、ここは他にほぼ無い。

---

## 案3: 外国企業を看板にする

**なぜ**: 2026-08-24 に 20-F 対応を入れました。**TSMC・ASML・トヨタ・ソニーの
SEC 提出書類を日本語で読めるアプリは、他に見当たりません。**
狭いが、**確認できて、真似には手間がかかる**差別化です。

しかも日本の個人投資家にとって、TSMC とトヨタとソニーは
「知っているのに決算は読んだことがない」の典型です。

**注意**: 20-F は年1回です。「四半期ごとに追える」とは言えません。
四半期は 6-K から取る作業が途中です(`FOREIGN_ISSUER_SUPPORT_2026-08-24.md`)。
**言い方を間違えると期待外れになります。**

---

## 案4: 出典を「見せる」ものにする

**なぜ**: 「すべての記述に出典がある」は既に実装され、コードで強制されています。
**でもユーザーから見て、それが伝わっていません。** 根拠チップは出ていますが、
「押すと原文の該当箇所に飛ぶ」という体験が弱い。

**やること**: 数字をタップ → 原文の該当段落がハイライトされて出る。
一度体験すれば「これは要約記事とは違う」と分かります。
**実装済みの一番強い資産を、体験にしていないのが今の状態です。**

---

## 順番についての意見

1. **案1(通知)** — 唯一「また開く理由」を作る。ChatGPT が構造的にできない。工数は大きいが効果も大きい
2. **案4(出典を見せる)** — 既にあるものを見せるだけ。工数が小さい割に効く
3. **案2(差分)** — データは揃っている。文章の差分まで行くと独自性が出る
4. **案3(外国企業)** — 実装済み。**看板の掛け替えなので工数ゼロ**。ただし年1回の制約を正直に

**ただし前提**: 実ユーザー4人(`USAGE_REALITY_2026-08-24.md`)。
**差別化は「見つかった後」に効きます。** 見つかっていない段階では、
案3(看板の掛け替え、工数ゼロ)以外は急ぐ理由が薄い、というのが正直なところです。
