## 1. App Store「このバージョンの新機能」

**採用案(短い方)**

```
米国以外の企業に対応しました。TSMC・ASML・トヨタ・ソニーなど、
米国市場に上場する外国企業の年次報告書(20-F)を日本語で読めます。

・画面を作り直しました。ホームは保有銘柄の売上・利益が一覧できる盤面に、
  会話は銘柄ごとの独立した画面になりました
・配色を刷新しました
・有料プランの回答が上位のAIモデルになりました
・回答をそのまま共有できるようになりました
```

**長い方(枠が余る場合)**

```
■ 米国以外の企業に対応
TSMC・ASML・SAP・トヨタ・アリババ・シェル・ノボノルディスク・ソニーなど、
米国市場に上場する外国企業に対応しました。これらの企業は 10-K ではなく
20-F という様式で年次報告書を出します。国際会計基準(IFRS)で書かれた
決算にも対応しました。
※ 20-F は年1回の提出のため、四半期ごとの更新はありません。

■ 画面の作り直し
ホームを盤面にしました。保有している銘柄の売上・営業利益・純利益が
前年比つきで並びます。会話は銘柄ごとの独立した画面になり、
質問と回答が見分けやすくなりました。

■ 配色の刷新
落ち着いた墨色を基調に、読むための画面として作り直しました。

■ 有料プランの回答が上位モデルに
月額プランをご利用の方は、より高性能なAIモデルが回答します。

■ 回答の共有
回答を出典つきでそのまま共有できるようになりました。
```

**書かないもの**(審査と誤解の両方の理由で)

- 「AIが投資判断を助ける」等、助言に読める表現。**Description の免責と矛盾する**
- 「正確」「確実」。回答は生成物で、保証はできない
- サーバ側の変更(モデルの単価・設定の期限・App Attest)。**ユーザーには関係がない**

## 2. 審査メモに足すこと

`docs/release/APP_STORE_SUBMISSION_NOTES.md` に追記する内容。

> このバージョンから、米国市場に上場する外国企業(Form 20-F 提出者)に対応しました。
> データ源は従来と同じく SEC EDGAR の公開提出書類のみです。新しい権限・
> 新しいトラッキング・新しい外部送信はありません。
>
> 有料プランで使用するAIモデルが変わりますが、回答の生成経路と免責表示は同一です。
> 引き続き投資助言・売買推奨・目標株価の提示は行いません。

## 3. X(@0xt4dano)用

**告知(1本目)**

```
Kabuyomi を更新しました。

TSMC・ASML・トヨタなど、米国に上場している外国企業に対応しました。
これらは 10-K ではなく 20-F という様式で決算を出すので、
今まで開けませんでした。

英語の決算書を、根拠の場所つきで日本語で読めます。
```

**実物(2本目、スクショつき)**

```
例えば TSMC の年次報告書。
売上・営業利益・純利益と、その数字がどの書類のどこから来たかが出ます。

要約だけ読んで終わりにしないための道具です。
```

※ 投稿はオーナー判断。数字を出すなら**実際の画面のスクショ**を添える。文字だけだと読まれない。
