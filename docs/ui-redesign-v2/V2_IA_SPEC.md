# Kabuyomi v2 IA 刷新仕様(骨格の組み替え)

決定 2026-08-22。リリースオーナー指示「元の形を維持する必要はない。世の中が見やすいと
しているもので」。規範は**金融アプリの世界標準 = ウォッチリスト・ファースト**、
具体的には Apple 純正株価アプリの形(検索が上、自分の銘柄が板、その下にフィード)。
iOS ユーザーの筋肉記憶をそのまま使う。視覚言語は V2_REDESIGN_SPEC.md(terminal-grade
dark editorial)を継続。

## 新しいタブ構成

| 旧 | 新 |
|---|---|
| リサーチ(汎用発見リスト) | **ホーム** — 盤面+新着の1スクロール |
| 履歴 | **研究** — 過去の Q&A アーカイブ(会社別) |
| 設定 | 設定(不変) |

タブは目的地、各タブが NavigationStack を持つ、という7月ルールは維持。

## ホーム(Apple 株価型・1スクロール)

1. **検索バー**(最上部固定、現行の searchable を移設)
2. **盤面(ウォッチリスト)**: 保存済み+最近の会社を密な板行で。
   各行: ticker(tabular)/社名1行/最新 filing(form+日付)/**デルタピル**
   (売上 YoY を株価アプリのピル形式で。朱=増/青=減、キャッシュ済み metrics から)
   /未読ドット(filedAt > 最終閲覧、ローカル永続)
3. **新着**: トラック中の会社の filing をキャッシュの filedAt 降順で時系列に。
   行 = 会社+form+日付+要約の verdict 1行。タップで会社ワークスペースへ
4. **空状態**: 盤面が空のときだけ現行のスターター企業リスト+ミッション文を表示。
   発見リストとしての「リサーチ」画面は消滅し、この空状態と検索に吸収される

## 会社ワークスペース

Phase 1 の v2 ドキュメント(折りたたみヘッダー/数値グリッド/チップ/質問コンポーザ)を
そのまま使う。変更なし。ホームの板行・新着行のどちらからも同じ画面に入る。

## 研究タブ(旧・履歴)

会社ではなく **Q&A アーカイブ**が主役: 過去の質問と回答を会社別グループの時系列で。
Phase 2 の 1.5 行圧縮スタイルを流用。会社行タップで会社ワークスペースへ、
質問行タップで該当会話へ。

## データの現実(サーバー変更なし)

- 盤面・新着はすべて既存のローカルキャッシュ(saved/recent、filing cache、metrics)から導出
- 未読状態は「会社ごとの最終閲覧時刻」をローカル永続に追加(AppModel の管轄)
- 通知(push)は本仕様のスコープ外。新着はアプリを開いた時点のキャッシュで良い

## 動かさないもの(背骨)

- 課金・StoreKit フロー、クレジット画面(Phase 2 のまま)
- 出典チップの存在感、会社ドキュメントの編集的構成
- view はサービスを作らない。導出ロジックは pure support + AppModel の既存状態から
- 日本語文言(新規画面の新文言は可、既存文言の変更は不可)
- Dynamic Type / Reduce Motion / VoiceOver

## 検証基準

- iOS ユニット既存 222 件グリーン(タブ構造に依存するテストは新IAに合わせて更新可、
  ただし挙動アサーションを弱めない)+ 新規導出ロジック(板行・新着・未読)のテスト
- 空状態→初会社保存→盤面表示、の一連をシミュレータで実機確認
