# 会話画面と設定画面の作り直し(2026-08-26)

オーナー「会話のUIと設定のUIがとてもゴミ」。**シミュレータで実物を見て**書いた指摘。
推測ではなく画面から取った事実。

**2026-08-26 対応済み。** 下の「直す方針」は全部入れた。実物での確認も同じ手順で取り直している。
残しているのは法務文面のみ(最下部)。

## 会話画面 — 同じことを 5 回言っている

実機の 1 画面に並んでいた文言:

```
Apple Inc.                                    ← ナビタイトル
10-Q ・ 2026/05/01 に基づく会話
この資料について気になることを聞いてください        ← ①
　この資料を深掘りする                          ← ②
　質問は対象資料と会話の文脈に基づいて回答されます    ← ③
（提案チップ 4 つ）
この資料について質問する                        ← ④ 下部バー
[この資料について質問]                          ← ⑤ プレースホルダ
```

**「この資料について質問」が 4 回。見出しが 5 段。中身は提案チップ 4 つだけ。**

- **画面の 6 割が空白。** 会話が無い状態が「空っぽ」にしか見えない
- **提案チップ右端の ↖ が意味不明。** 押すと送信なのか入力欄に入るのか分からない
- **入力欄が最初は畳まれている。** 「質問して」と 4 回言いながら、質問する場所が画面に無い
- **背景が上下で割れていて、意味のない境界線**が入る
- 送信ボタンは有効/無効で**同じ形**。薄いだけで、押せるかどうか分からない
- 0 クレジット時の文言が「質問にはクレジットが必要です」で、
  コンポーザの `disabledReason`「残高不足」と**別の言い方**になっている

### 直す方針

- **見出しを 1 つに。** 「Apple Inc. / 10-Q 2026-05-01」だけ残し、①②③④を消す
- **入力欄を最初から出す。** この画面は質問のためだけにある。畳む理由がない
- 提案チップは**入力欄のすぐ上**へ。↖ をやめ、押した結果が見た目で分かる形に
- 空白は過去の会話で埋まる。空のときだけ提案を出す(実装はそうなっているが、
  見出しが多すぎて「空」に見えない)

## 設定画面 — 見出しの方が中身より多い

| セクション | 項目数 |
|---|---|
| クレジット | 1 |
| AI 利用 | 1 |
| 表示 | 1 |
| サポートとデータ | 2 |

**4 セクションに 5 項目。** 見出しが目次として機能せず、ただの区切り線になっている。

- **「アカウントとリサーチ / 利用環境を確認・管理」** — 「設定」の下で設定だと
  言い直しているだけの埋め草。消す
- **「AI 利用への同意」がオフだと質問できない。** なのに他のトグルと同じ重み。
  オフのまま質問しようとして初めて分かる。**この画面で一番重要なスイッチ**
- **「ローカルデータをリセット」が赤字でむき出し。** 破壊的操作が他の行と同じ並びに、
  区切りも確認もなく置かれている
- **「残り 0 クレジット」なのに、その場でできることが無い**
- フッターが **「SEC 10-K / 10-Q」**(20-F 対応済みなのに古い)

### 直す方針

- **セクションを 2 つに**(「アプリ」「データとサポート」)
- **AI 同意を一番上に単独で。** オフなら「質問できません」と赤で明示
- **リセットは一番下・区切り・確認つき**
- 「アカウントとリサーチ〜」の 2 行を削除

## 横断: 書類名の直書き

**今日 3 箇所直したが、まだ残っている**(ようこそ画面 / ホームのミッション文 / 設定フッター)。
`10-K / 10-Q` を文面に埋め込むのをやめ、**対応書類の呼び名は 1 箇所**にまとめる。
20-F を足すたびに全画面を探す羽目になっている。

会話が空のときだけ、内容をスクロール領域の下端へ寄せている
(`RedesignEmptyChatAnchor`)。特大文字では掛けない — `containerRelativeFrame` は
高さを固定するので、掛けると溢れた分が切れる。

UI テストの `redesign.composer.expand` は消えた(畳む入り口が無くなったため)。
`ShellParityUITests` は `redesign.composer.field` を見るように差し替えた。
資料の面には無い / 会話画面には最初からある、という invariant はそのまま。
