# Kabuyomi v2 UI 刷新仕様

決定 2026-08-22(リリースオーナー回答: ダーク基調・金融系 / 情報密度と使いやすさの両立 / 全画面)。
7月版(docs/ui-redesign/REDESIGN_SPEC.md)の**ナビ骨格は正しいので残す**。
変えるのは視覚言語と密度。「静かな読み物」→「**ターミナル級の密度を持つダークな編集面**」。

## コンセプト

**terminal-grade dark editorial.**
編集的な読み体験(要約→数値→根拠→対話)はそのまま、
金融端末の密度・数字の格・ダークの没入を与える。
チャットボットにも株価ダッシュボードにも見せない、は継続。

## 何を残すか(変更禁止)

- 3タブ(リサーチ/履歴/設定)+ NavigationStack、戻るジェスチャ、tab bar の表示規則
- AppModel の契約(view は API client / persistence / StoreKit を作らない)
- 日本語文言・法務文言
- Dynamic Type / Reduce Motion / VoiceOver。密度を上げても Dynamic Type 拡大時は破綻せず縦積みに逃がす
- 状態の区別(未対応/オフライン/クレジット不足/購入保留/機能無効)

## デザイントークン(Theme.swift v2)

ダークが設計基準。ライトは機能として残す(派生値、二級市民でよい)。

### 基調

| token | dark | 意図 |
|---|---|---|
| canvas | `#0A0E13` | 最背面。純黒でなく青みの墨 |
| paper | `#10161D` | 読み面 |
| elevated | `#161E27` | カード・シート |
| inputWell | `#0D1319` | 入力・埋め込み面 |
| separator | white 8% | 細罫。境界は影でなく罫線で |
| ink | `#E8ECF0` | 本文 |
| inkSoft | `#9AA7B4` | 補助 |
| inkMuted | `#6B7683` | ラベル・脚注 |

### アクセント・意味色

| token | dark | 用途 |
|---|---|---|
| accent | `#3DDCC3`(teal) | 操作・リンク・選択。**system blue を置き換える** |
| gain | `#FF6B5E`(朱) | 上昇・増加。**日本の相場慣習: 上げ=赤** |
| loss | `#4E9CF5`(青) | 下降・減少。上げ下げは必ず矢印/符号を併記(色だけに頼らない) |
| caution | `#E8B04B` | 注意・保留状態 |

gain/loss は semantic token として一元化し、慣習を反転したくなったら1行で切り替え可能にする。
teal は gain/loss と衝突しないために選ぶ(緑=上げ/下げのどちらにも読ませない)。

### 数字の格

- 金額・比率・EPS は **tabular numerals + セミモノスペース**(`.monospacedDigit()` 基本、主要数値は SF Mono 検討可)
- 主要数値は大きく細く(weight .medium 以下)、増減率は gain/loss 色 + 矢印
- マイクロラベル(「売上高」等)は inkMuted・小さめ・トラッキング広め

## 密度の具体策(スクリーンショット監査 2026-08-22 に基づく)

1. **折りたたみヘッダー**: 会社名+form+日付+資料件数のヘッダーはスクロールで
   コンパクトバー(1行)に収束。常駐で画面1/4を占有している現状を解消
2. **ソースチップの識別性**: 現状「利益率」×3 が同一表示で並ぶ。
   ラベル + **セクション種別バッジ + 抜粋の先頭断片**で1つずつ区別可能にする(7月spec の
   deterministic preview を実装で徹底)
3. **主要数値グリッド**: 罫線区切りの密なグリッドへ。セル内=ラベル/値/増減の3段を詰め、
   既存 RedesignTrendChart のミニバーはセル右に保持
4. **セクション折りたたみ**: 推移・ポイント等は collapsible。開閉状態は画面内で保持
5. **リスト行の圧縮**: 発見画面・履歴の行高を下げ、1画面あたりの行数を上げる

## 画面別

- **リサーチ(発見)**: 検索を最上部固定。スターター企業は密な行(ロゴ枠は縮小、
  ticker を tabular で左寄せ)。ミッション文は初回のみ目立たせ、以降は控えめに
- **会社ワークスペース**: 上記1-4。質問コンポーザは底部固定のまま、送信可能状態を accent で明示
- **資料・根拠一覧 / 引用詳細**: バッジ+断片プレビューで行を識別可能に。原文と訳の並置は維持
- **履歴**: 最新質問・回答数・時刻を1行半に圧縮
- **設定 / クレジット**: トークン差し替え中心。残高数値は tabular で大きく。
  購入行の状態(保留/失敗/復元)は caution/gain/loss で即読めるように
- **アプリアイコン・ストア素材**: 本仕様のスコープ外(別途)

## 実装フェーズ

1. **Phase 1**: Theme v2 トークン + 共通プリミティブ(チップ/数値セル/セクションヘッダ/
   折りたたみヘッダ)+ 会社ワークスペース(RedesignRootView / ResearchPresentationSupport /
   RedesignTrendChart)
2. **Phase 2**: 発見・履歴・設定・クレジット・資料/引用詳細

各 Phase 後にシミュレータ実機確認 → リリースオーナーのレビュー → 次へ。

## 検証基準

- `xcodegen generate` 後、iOS ユニット 206 件が全て通る(挙動契約は不変のはず)
- Dynamic Type XXL でレイアウト破綻なし(縦積みに退避)
- Reduce Motion で折りたたみアニメーションが即時切替になる
- ライトモードでも判読可能(美しさは要求しない、破綻しないこと)
